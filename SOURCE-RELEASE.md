# Current development source: 0.5.8

PATCH-NOTES-0.5.8.md is the cumulative change summary from public v0.5.0 (internal v0.5.4) to this development build. Earlier patch notes remain historical. Measured 0.5.7 memory results and their limits are in MEMORY-PERFORMANCE.md; AUDIO-PROVIDERS.md describes current timing support. Existing release tags and downloads are preserved. This working tree is not a published release.

Build on Windows x64 using Node.js 24 and the Rust MSVC toolchain: npm ci, cargo fetch --locked --manifest-path windows/QuranMushaf.Rust/Cargo.toml, then npm run publish:windows. Rust standard-library notices (rust-docs component) and Windows C++ build tools are required. Inno Setup 6 is needed only for npm run installer:windows. Normal builds use the included processed Quran resources; optional raw-data re-import commands require upstream inputs described in their scripts.

Run npm run check:release for the full browser/dependency checks, then npm run package:portable to create a verified ZIP under outputs/releases. Build manifests record the source commit, dirty state, content fingerprint and tool versions. The web build records its source snapshot; native packaging refuses an older or modified WebApp. Finish all source edits, including documentation/checksums, before rebuilding and packaging. These checks support traceability, not a promise of byte-identical compiler output across machines. GitHub Actions keeps test artifacts; it does not publish a release automatically.

The host uses WebView2, not .NET. The historical Windows project path is retained only for Assets/app.ico, referenced by the Rust resource compiler. Preserve .gitattributes so Git does not alter resource bytes. SOURCE-FILES.sha256 covers this source snapshot, excluding itself and .git metadata. Licenses and resource notices remain applicable.
